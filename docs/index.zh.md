# Navi Agent

Navi Agent 是一个面向终端和微信场景的精简 Agent 运行时。它将模型驱动的
运行时与工作区工具、持久化会话、记忆、可观测性和受治理的进化机制组合在一起。

## 从这里开始

- [安装并运行 Navi Agent](getting-started.md)
- [配置模型与运行时](configuration.md)
- [了解工具权限](permissions.md)
- [接入微信网关](gateway.md)

## 核心能力

| 领域 | 能力 |
| --- | --- |
| 运行时 | 支持会话的模型与工具执行，包含 steer 和取消 |
| 工具 | 终端、文件、代码、Web、任务、记忆和调度能力 |
| 记忆 | 持久化用户记忆和可搜索的会话历史 |
| 可观测性 | 运行时事件、Trace、健康摘要和回放数据 |
| 网关 | 微信协议接入和私聊访问控制 |
| 进化 | 受治理的 Prompt 和 Skill 候选项，与在线执行解耦 |

Navi Agent 将 CLI 启动目录作为工作区。如需访问其他目录，必须通过
`--add-dir` 显式授权。
